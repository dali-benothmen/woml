# Changelog

## 0.1.1

- Scope every WOML element as a normal HTML tag instead of an invalid,
  unrecognized HTML element.
- Preserve native HTML handling for `<script>` and its embedded JavaScript.

## 0.1.0

- Register the WOML language and `.woml` files.
- Reuse HTML highlighting with embedded JavaScript support.
- Highlight WOML runtime globals and reference expressions.
- Add starter workflow and step snippets.
