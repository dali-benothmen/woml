# WOML v1.0.0 Dependency Review

Review date: 2026-08-17

This is the dependency-security and license record for the v1.0.0 release
candidate. It covers the committed Bun and Cargo lockfiles, not arbitrary
modules imported by workflow authors.

## Advisory review

The first live review found one JavaScript advisory and six Rust
vulnerabilities. None were accepted for release:

| Dependency path | Finding | Resolution |
| --- | --- | --- |
| AJV 8.17.1 | `GHSA-2g4f-4pwh-qvx6`, ReDoS when `$data` is enabled | Updated every direct and transitive AJV instance to 8.20.0 and added a lockfile override |
| `postgres-protocol` 0.6.10 | `RUSTSEC-2026-0179` and `RUSTSEC-2026-0180` | Updated to 0.6.12 |
| `tokio-postgres` 0.7.13 | `RUSTSEC-2026-0178` | Updated to 0.7.18 |
| `rustls-webpki` 0.101.7 through `reqwest` 0.11 | `RUSTSEC-2026-0098`, `RUSTSEC-2026-0099`, and `RUSTSEC-2026-0104` | Updated `reqwest` to 0.12.28, removing the complete Rustls 0.21/WebPKI 0.101 path |
| `rand` 0.8.5 and 0.9.1 | `RUSTSEC-2026-0097` informational unsoundness warning | Compatible dependency updates removed both versions |
| `rustls-pemfile` 1.0.4 | `RUSTSEC-2025-0134` unmaintained warning | Removed with the `reqwest` upgrade |

Final live results:

- `bun audit --json`: no advisories (`{}`);
- `cargo audit --json`: zero vulnerabilities and zero warnings;
- RustSec database: 1,216 advisories, commit
  `69f93e1d081d8b6fbee010e48f0b5e0d13661415`, updated 2026-08-12; and
- Cargo lockfile: 342 dependencies.

Both live audits must run again immediately before publication because an
advisory result is time-sensitive.

## License review

Cargo metadata reports a license expression for all 342 Rust packages. The
locked graph uses permissive license families: Apache-2.0, MIT and MIT-0, ISC,
BSD-2-Clause, BSD-3-Clause, Zlib, Unicode-3.0, BSL-1.0, Unlicense,
CDLA-Permissive-2.0, 0BSD, and compatible alternatives. Two expressions offer
LGPL-2.1-or-later only as an alternative to MIT or Apache-2.0; WOML uses the
permissive alternative. No package reports GPL, AGPL, SSPL, BUSL, Commons
Clause, or an unknown license.

The bundled JavaScript runtime graph reports MIT, Apache-2.0, BSD-3-Clause,
and ISC licenses. Every bundled package reports a license and no prohibited or
unknown license was found.

WOML itself is Apache-2.0. The main and native npm archives carry the WOML
`LICENSE` and `NOTICE.md`; the source repository retains the exact dependency
lockfiles and this review record.

## Accepted operational boundary

The dependency review does not make arbitrary workflow modules, database
servers, provider endpoints, container base images, or operator-installed
software part of WOML's reviewed supply chain. Operators must review those
components separately. The release workflow builds from exact lockfiles and
publishes only the sealed artifact family produced by the reviewed commit.
