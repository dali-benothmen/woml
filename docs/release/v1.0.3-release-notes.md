# WOML 1.0.3

WOML 1.0.3 is a README patch release. The 1.0.2 tarball on npmjs.com
shipped the old hello-world quick example; this release replaces it with
the Smart File Organizer showcase and ships the new README to npm. The
release artifacts are otherwise identical to 1.0.2.

## Highlights

- **New quick example on npm**: "Organize your Downloads folder" — a
  complete, runnable workflow that scans a folder, loops over every file
  with `<for-each>`, routes each one through a `<choose>` decision by
  extension, and moves it into `Images/`, `Docs/`, `Videos/`, `Archives/`,
  or `Misc/` with `fs.rename`. Uses real npm packages (`fs`, `path`) and
  no external services.
- **Mermaid diagram** of the workflow below the code, making the
  `<choose>` + `<for-each>` + `<script>` pattern visually obvious.
- **Bun install option** added in the Installation section so the
  canonical `bun add --global woml-cli` command is documented alongside
  the existing npm option.
- Package identity frozen at `woml-cli@1.0.3` (public) and the matching
  `@woml-org/cli-*@1.0.3` native engines for darwin-x64, darwin-arm64,
  win32-x64-msvc, win32-arm64-msvc, linux-x64-gnu, and linux-arm64-gnu.
- All six manifests pinned at `1.0.3`; the private compiler
  (`@woml/compiler`), VS Code extension (`woml-language`), and root
  monorepo (`woml-repository`) packages follow the same version.

## Release infrastructure

- `core/woml-native/tests/separation.rs` assertion updated to require
  `woml-engine = "1.0.3"`.
- `Cargo.lock` regenerated.
- `examples/production/deployment/Dockerfile` bumped to install
  `woml-cli@1.0.3` by default.

## Installation

```bash
bun add --global woml-cli
```

```bash
npm install --global woml-cli
```

## Upgrading

`bun update -g woml-cli` or `npm update -g woml-cli` will move a 1.0.x
installation to 1.0.3. No workflow or API changes — this is a
documentation-only release.
